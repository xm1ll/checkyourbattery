# Check Your Battery

Переносимые индикаторы заряда для области уведомлений Windows 11 x64. Написаны на C++20 с Win32 и C++/WinRT.

Запустите `build\CheckYourBattery.exe`. Сопряжённые Bluetooth-устройства и поддерживаемые приёмники 2,4 ГГц отображаются обычными значками в области уведомлений Windows рядом с часами. При наведении видны имя устройства, заряд и состояние подключения.

- Если Windows поместила значки под стрелкой `˄`, перетащите их в основной ряд или включите в **Параметры → Персонализация → Панель задач → Другие значки в области уведомлений**. [Настройка панели задач Windows](https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-taskbar-in-windows)
- Левый щелчок открывает настройки. Снимите галочку напротив устройства, чтобы скрыть его. **«Зарядка в процентах»** переключает отображение между числом под значком и полоской. Если все устройства скрыты, значок батареи остаётся доступен для открытия настроек.
- Меню по правому щелчку открывается над панелью задач. Кнопка «Выйти» также есть в окне настроек. Приложение проверяет заряд раз в минуту.

## Совместимость

Приложение ищет сопряжённые устройства Bluetooth Classic и LE. Сначала оно проверяет сведения о батарее, доступные через Windows. Для подключённых устройств LE оно также может прочитать стандартную характеристику Battery Level сервиса GATT Battery Service.

Поддерживаются две модели USB-приёмников 2,4 ГГц:

- **LAMZU Maya X, 8K** (`373E:001E`) передаёт процент напрямую. [Протокол LAMZU Maya X](https://github.com/Sheroune/lamzu-battery-monitory)
- **Razer Barracuda X (2022), Macronix** (`1532:0552`) передаёт напряжение. Виджет оценивает процент по кривой разряда и ставит `≈` в подсказке. [Протокол USB-приёмника Barracuda X](https://github.com/HeyOkay/HaloBattery/blob/main/docs/protocols.md#razer-barracuda-x-2022-24-ghz)

Другим фирменным приёмникам нужна поддержка их протокола. Виджет показывает один процент на устройство. Отдельные показатели для левого и правого наушников и кейса не считываются.

Подробнее о стандартном сервисе батареи можно прочитать в [документации Microsoft по Bluetooth GATT](https://learn.microsoft.com/en-us/windows/apps/develop/devices-sensors/gatt-client).

## Сборка

Из PowerShell на Windows 11 x64 запустите следующую команду. Она скачает зафиксированные версии LLVM-MinGW и Microsoft C++/WinRT в `.toolchain` и соберёт `build\CheckYourBattery.exe`. Для следующих сборок достаточно `.\build.ps1`.

```powershell
.\build.ps1 -Bootstrap
```

На компьютере, где запускается готовый `.exe`, инструменты сборки не нужны.

## Безопасность и ресурсы

Готовое приложение запускается с правами текущего пользователя. Заряд считывается через локальные Windows Bluetooth API и HID-интерфейсы поддерживаемых приёмников. Настройки видимости и формата сохраняются в `HKEY_CURRENT_USER\Software\CheckYourBattery`. Демонстрационный режим их не меняет. Готовый `.exe` не использует интернет, не устанавливает драйверы, не регистрирует горячие клавиши и не изменяет автозагрузку. Сборка включает ASLR, DEP, Control Flow Guard и защиту стека. Поиск системных DLL ограничен системным каталогом Windows. `.exe` не подписан Authenticode.

В промежутках между проверками процесс ожидает системные события. Значки перерисовываются при изменении показаний или перезапуске Проводника. Сетевые загрузки выполняет только явная команда сборки `-Bootstrap`, которая сверяет SHA-256 архивов перед распаковкой.

## Проверка

```powershell
# Демонстрационные значки в трее
.\build\CheckYourBattery.exe --demo

# Диагностика обнаружения реальных устройств без открытия окна
.\build\CheckYourBattery.exe --scan | Out-Host
```
